# Slotly: техническая спецификация

## Iteration 1.0 — Foundation

Текущая версия предоставляет минимальный фундамент веб-приложения:

- FastAPI-приложение;
- серверный HTML-шаблон на Jinja2;
- статические CSS-стили;
- стартовую страницу и health-check.

База данных, расписание, слоты, бронирования и административные функции не
входят в эту итерацию и будут описаны по мере развития проекта.
