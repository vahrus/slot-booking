# Slotly

Slotly — учебное веб-приложение для онлайн-бронирования временных слотов.

## О проекте

Проект создаётся поэтапно как понятный пример сервиса онлайн-записи для малого
бизнеса. Текущая версия содержит только запускаемый фундамент приложения и не
реализует работу со слотами или бронированиями.

## Технологии

- Python 3.11+
- FastAPI
- Uvicorn
- Jinja2
- HTML5 и CSS3

## Текущий статус

Завершена Iteration 1.0 — Foundation: доступны стартовая страница, статические
стили и health-check. База данных и бизнес-логика пока отсутствуют.

## Требования

- Python 3.11 или новее
- `pip`

## Установка

Создайте и активируйте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

## Запуск

```bash
python -m uvicorn app.main:app --reload
```

После запуска приложение доступно по адресу:

```text
http://127.0.0.1:8000
```

## Проверка приложения

- Главная страница: http://127.0.0.1:8000
- Health-check: http://127.0.0.1:8000/health
- Документация FastAPI: http://127.0.0.1:8000/docs

Health-check также можно проверить из терминала:

```bash
curl -i http://127.0.0.1:8000/health
```
