# Slotly

Slotly — учебное веб-приложение для онлайн-бронирования временных слотов.

## О проекте

Проект создаётся поэтапно как понятный пример сервиса онлайн-записи для малого
бизнеса. Текущая версия позволяет владельцу создавать расписание, а посетителю —
выбирать дату, записываться на свободное время и получать подтверждение.
Отмена бронирования будет реализована в следующей итерации.

## Технологии

- Python 3.11+
- FastAPI
- Uvicorn
- Jinja2
- SQLAlchemy 2.x
- SQLite
- HTML5 и CSS3

## Текущий статус

Завершена Iteration 4.0 — Booking: доступны создание расписания, просмотр
слотов, запись на свободное время, хранение данных клиента и защита занятого
слота. После подтверждения пользователь видит страницу успешной записи.

Отмена бронирования будет реализована в следующей итерации.

## Возможности

- создание свободных временных слотов через `/admin`;
- хранение расписания и бронирований в SQLite;
- просмотр слотов на выбранную дату;
- запись на свободный слот;
- хранение имени и контакта клиента;
- защита занятого слота от повторной записи;
- страница подтверждения бронирования;
- отображение статуса «Свободно» / «Занято».

## База данных

Модель данных содержит связь один-к-одному:

```text
Slot
  ↓ 1 : 0..1
Booking
```

Файл `data/booking.db` создаётся автоматически при запуске приложения и
исключён из Git. Таблица слотов хранит дату и время в структурированном виде,
а ограничения SQLite защищают уникальность слотов, бронирований и внешнего
ключа.

## Требования

- Python 3.11 или новее
- `pip`

## Установка

Создайте и активируйте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

## Запуск

```bash
python -m uvicorn app.main:app --reload
```

После запуска приложение доступно по адресу:

```text
http://127.0.0.1:8000
```

## Проверка приложения

- Главная страница: http://127.0.0.1:8000
- Управление расписанием: http://127.0.0.1:8000/admin
- Health-check: http://127.0.0.1:8000/health
- Документация FastAPI: http://127.0.0.1:8000/docs

Health-check также можно проверить из терминала:

```bash
curl -i http://127.0.0.1:8000/health
```

## Демонстрация

1. Запустите приложение.
2. Откройте http://127.0.0.1:8000/admin.
3. Создайте Slot.
4. Откройте главную страницу.
5. Выберите ту же дату.
6. Нажмите «Записаться».
7. Введите имя и контакт.
8. Подтвердите запись.
9. Убедитесь, что открылась страница подтверждения.
10. Вернитесь к расписанию.
11. Убедитесь, что слот отображается как «Занято».
