# Slotly

Slotly — учебное веб-приложение для онлайн-бронирования временных слотов.

## О проекте

Проект создаётся поэтапно как понятный пример сервиса онлайн-записи для малого
бизнеса. Текущая версия позволяет владельцу создавать временные слоты, а
посетителю — выбирать дату и просматривать расписание. Пользовательское
бронирование пока не реализовано.

## Технологии

- Python 3.11+
- FastAPI
- Uvicorn
- Jinja2
- SQLAlchemy 2.x
- SQLite
- HTML5 и CSS3

## Текущий статус

Завершена Iteration 3.0 — Slots: доступны создание временных слотов,
просмотр расписания, фильтрация по дате и административная страница `/admin`.
Слоты хранятся в SQLite и защищены от дублирования даты и времени.

На текущем этапе реализованы слой хранения и управление расписанием.
Пользовательский сценарий бронирования будет добавлен в следующих итерациях.

## Возможности

- создание свободных временных слотов через `/admin`;
- хранение расписания в SQLite;
- просмотр слотов на выбранную дату;
- сортировка слотов по времени;
- защита от создания дублирующихся слотов;
- отображение статуса слота.

## База данных

Модель данных содержит связь один-к-одному:

```text
Slot
  ↓ 1 : 0..1
Booking
```

Файл `data/booking.db` создаётся автоматически при запуске приложения и
исключён из Git. Таблица слотов хранит дату и время в структурированном виде,
а ограничения SQLite защищают уникальность слотов, бронирований и внешнего
ключа.

## Требования

- Python 3.11 или новее
- `pip`

## Установка

Создайте и активируйте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

## Запуск

```bash
python -m uvicorn app.main:app --reload
```

После запуска приложение доступно по адресу:

```text
http://127.0.0.1:8000
```

## Проверка приложения

- Главная страница: http://127.0.0.1:8000
- Управление расписанием: http://127.0.0.1:8000/admin
- Health-check: http://127.0.0.1:8000/health
- Документация FastAPI: http://127.0.0.1:8000/docs

Health-check также можно проверить из терминала:

```bash
curl -i http://127.0.0.1:8000/health
```

## Демонстрация

1. Запустите приложение.
2. Откройте http://127.0.0.1:8000/admin.
3. Создайте несколько слотов на одну дату.
4. Откройте главную страницу.
5. Выберите ту же дату.
6. Убедитесь, что расписание отображается по возрастанию времени.
